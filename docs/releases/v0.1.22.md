## 文档与发布流程 / Documentation and releases

- **HTML 说明文档**：https://neko233-com.github.io/banhack233/ （英文：`en.html`）。与本版本 README 同源，提供章节检索、代码复制、配置下载和移动端目录。
- **仅正式标签触发**：`vX.Y.Z` 启动一次工作流；main push、PR、普通/预发布标签及 Release 描述编辑均不会触发构建。
- **通过后才发布**：Linux/Windows 测试、vet、Linux race、ShellCheck、文档和发布门禁测试通过后构建六个平台资产；上传完草稿资产后发布 Release，再部署 Pages。
- **最新版保护**：旧标签重跑不会覆盖最新文档；页面和 `version.json` 标明实际部署版本。
- **离线文档与校验和**：新增 `banhack233-docs-v0.1.22.tar.gz` 和 `SHA256SUMS.txt`，原有二进制文件名与安装方式保持兼容。
- 修正文档中“默认只统计密码失败”的过时说明；当前默认覆盖多种认证失败，另提供仅统计密码失败的配置示例。

### Upgrade notes

This release adds bilingual GitHub Pages documentation, an offline HTML archive, and SHA-256 checksums. Only stable version tags start Actions; checks and release builds gate publication, and Pages deployment waits for a published Release. Older releases cannot replace newer documentation.

No host configuration migration is required. Existing configuration files are preserved by installation. Per-user counting still enforces bans by source IP; trusted shared office addresses should remain whitelisted.

### Installation

```sh
curl -fsSL https://raw.githubusercontent.com/neko233-com/banhack233/main/scripts/install.sh | sh
```

### Verify downloads

Download `SHA256SUMS.txt` alongside the desired assets and run `sha256sum --ignore-missing -c SHA256SUMS.txt` on Linux. Extract the docs archive and open `index.html` or `en.html` for offline reading.
